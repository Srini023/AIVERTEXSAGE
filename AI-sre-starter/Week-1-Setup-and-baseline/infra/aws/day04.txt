CloudWatch: enabled by default, confirm logging policies attached.


AWS (CLI setup)

aws budgets create-budget \
  --account-id <AWS_ACCOUNT_ID> \
  --budget-name COSTCONTROL \
  --budget-type COST \
  --time-unit MONTHLY \
  --budget-limit Amount=10,Unit=USD \
  --time-period Start=2026-10-01T00:00:00Z,End=2026-12-31T00:00:00Z \
  --notifications-with-subscribers file://budget-notifications.json


budget-notifications.json
[
  {
    "Notification": {
      "NotificationType": "ACTUAL",
